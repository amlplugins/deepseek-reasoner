# @amlplugins/deepseek-reasoner

Native `@ai-sdk/deepseek` SDK re-exported under the `@amlplugins` namespace.

> DeepSeek Reasoner — deepseek-reasoner (R1) chain-of-thought reasoning model via @ai-sdk/deepseek.

## Install

```bash
npm install @amlplugins/deepseek-reasoner
```

## Use

```ts
import { /* named exports from @ai-sdk/deepseek */ } from "@amlplugins/deepseek-reasoner";
// or
import sdk from "@amlplugins/deepseek-reasoner";
```

This package additionally re-exports `ai` under the `secondary` namespace.

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
